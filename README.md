# CalStitch

[English](README.en.md)

CalStitch 是 iPhone 的行事曆規則工具。在 CalStitch 設規則，在原本的行事曆看行程。

- 以西元、農曆或二十四節氣安排重複事件。
- 挑選要加入的通訊錄生日，以姓名或暱稱命名，寫入選定的行事曆。
- 用分類和次類整理規則；用子規則安排準備事項與後續行程。
- 套用前預覽事件，並可批次調整多條規則。

只把想要的節日、紀念日和聯絡人生日加到自己的行事曆。不必訂閱整份節日行事曆，也不用開啟顯示所有聯絡人生日的行事曆。

支援中文及英文介面。iPhone 版已在 [App Store](https://apps.apple.com/tw/app/calstitch/id6838189548) 上架。
