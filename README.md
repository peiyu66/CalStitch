# CalStitch

[English](README.en.md)

CalStitch 是 iPhone 的行事曆規則工具。在 CalStitch 設規則，在原本的行事曆看行程。

- 以西元、農曆或二十四節氣安排重複事件。
- 匯入通訊錄生日，先存成草稿，或套用到選定的行事曆。
- 用分類和次類整理規則；用子規則安排準備事項與後續行程。
- 套用前預覽事件，並可批次調整多條規則。

目前為測試版，尚未在 App Store 上架。英文文件已提供；目前測試版的介面為中文。
