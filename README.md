# CalStitch

繁體中文 · [English](README.en.md)

CalStitch 是 iPhone 的行事曆規則工具。在 CalStitch 設規則，在原本的行事曆看行程。

- 以西元、農曆或二十四節氣安排重複事件。
- 匯入通訊錄生日，先存成草稿，或套用到選定的行事曆。
- 用分類和次類整理規則；用子規則安排準備事項與後續行程。
- 套用前預覽事件，並可批次調整多條規則。

目前為測試版，尚未在 App Store 上架。英文文件已提供；目前測試版的介面為繁體中文。

## 開發

用 Xcode 開啟 `CalStitch.xcodeproj`，選擇 `CalStitch` scheme，再選 iPhone 模擬器或開發裝置。網站檔案在 `website/`；更新該目錄並推送到 `main` 後，GitHub Actions 會自動部署 GitHub Pages。
