## 3. UI 流程

以接近 Apple「提醒事項」的分類列表為出發點。規則總列表主要列出**根規則名稱和下次日期**，不另列子規則，也不是已生成的事件列表。

**規則列表 → 單條規則主頁（編輯／套用）；「預覽變更」為主頁通往下層的查看項目。**

- 規則主頁第一欄是事件標題，例如「媽媽農曆生日」，套用後作為行事曆事件名稱；維持既有欄位，不另加一欄。
- 「套用」放在單條規則主頁，只在新增或有未套用修改時需要，無須先看預覽。按下前不寫入行事曆。
- 「預覽變更」是有箭頭的列表項目，不做成動作按鈕；下層只列出將新增、更新或移除的項目，不提供套用或其他修改操作。
- 「查看日曆」理想上直接跳到 Apple 行事曆的指定日期，讓人看前後空檔，而不是開單一事件。把指定日期跳轉當成待驗證能力；若不可靠，保留明確的日期顯示，不改成事件詳情入口。
- 生日匯入走「選聯絡人 → 確認日期與要匯入的人 → 產生規則」。用 iOS 選人視窗，只使用所選聯絡人需要的姓名和生日欄位，取消不匯入，不要求存取整本通訊錄或背景同步。通訊錄列表／群組是否能作為篩選入口、在有限權限下有何限制，另做技術驗證。
- 可把從通訊錄匯入的同名生日寫進個人行事曆，讓使用者可自行隱藏太雜的 Apple「生日」行事曆。CalStitch 不改通訊錄、系統生日行事曆或手動建立的事件。

**UI 推進建議**：先做一套可走完的操作原型，再一起確認主流程，不逐頁等審。字體、按鈕位置和一般動線先由設計者決定；日期計算例外等會影響結果的行為，集中確認。

## 13. 分類、次類與規則外觀

- 分類、次類點標題旁的圖示，根規則及子規則點編輯頁事件標題旁的圖示，都能開啟同一個「圖示與顏色」面板。提供 30 種系統圖示、8 種常用色與 iOS 自訂色彩選擇器，可分別或一起恢復預設。點「完成」才接受變更，取消不儲存。
- 分類外觀以分類名稱為範圍；次類以「分類＋次類」為範圍，同名但不同分類互不影響。分類移空時不保留外觀。沒自訂時沿用家人、生活和一般分類的預設圖示，次類用資料夾。規則預設依曆別；圖示和顏色可獨立選擇。
- 外觀只存於 CalStitch，與日曆事件及規則日期無關。已存在的規則可單獨儲存外觀，不重算或寫入行事曆；全新規則的外觀隨規則首次套用一同儲存。
- 延續[第 12 節](version-history.md#section-12)及已確認的工具列和 App 圖示修改。英文本地化仍依[第 11 節](rules.md#section-11)安排。本批不開放實機行事曆寫入；iPhone 可在新增規則頁預覽單條規則外觀，也可用生日匯入草稿建立分類後試用，不會寫入行事曆。

本批驗證：既有模擬器點測分類、次類和單條規則的外觀入口，確認面板、原生自訂顏色入口、圖示選取及取消。開發版已簽名，安裝到指定的 iPhone Air，並在裝置 App 清單查到 CalStitch 1.0 (1)。未在實機啟動或寫入行事曆。

## 29. 試用回饋：首頁抬頭左緣對齊

- Air 的 0.1 (6) 中，副標「行事曆規則」與「批次調整」圖示仍比主標偏左。修正以主標「CalStitch」的 C 的可見左緣為基準；副標文字及圖示的可見左緣向右移到同一條垂直線。調整時用實際畫面核對，不以元件外框或一律套用同一個內距代替。分類及其縮排不跟著移動。

<a id="section-30"></a>

## 30. 試用回饋：預覽事件的變更標示

- 預覽事件列的待新增、待修改及待移除標示恢復靠右，不折到事件資訊下方。右側優先保留標示寬度，讓左側事件標題適度換行。維持原本每種狀態的色相，降低飽和度與亮度，仍須清晰可讀。已過去事件原有淡色處理不變。

<a id="section-31"></a>

## 31. 試用回饋：必填欄位提示色

- 未填的必填欄位仍以紅色提示，改用較柔和的低飽和紅；在淺色與深色模式中都須清楚可讀。填妥即恢復正常文字色，不改必填條件或套用規則。

<a id="section-32"></a>

## 32. 試用回饋：iPhone 畫面方向

- CalStitch 在 iPhone 只支援正向直式（`UIInterfaceOrientationPortrait`），不支援左右橫向或倒置直式。限制只作用於 CalStitch，不更改 iPhone 的系統旋轉設定。

<a id="section-38"></a>

## 38. 試用回饋：規則清單資訊位置

- 首頁規則列維持事件標題在左上。原先右側的「下次日期」與標題下方的規則摘要互換：規則摘要放在與標題同列的右側並靠右對齊；下次日期或「未套用／無後續日期」移到標題下方。不重新加入起始日，不更動事件日期計算。
- 一般大小保留可讀的標題和右側摘要；文字長或使用放大字體時允許有控制地換行，不以截掉整段資訊來對齊。

<a id="section-39"></a>

## 39. 試用回饋：批次調整的全選勾選框

- 頂層「全選」與分類全選同樣用勾選框顯示狀態，文案固定「全選」。全部選取時顯示勾，點按取消全選；未全選時點按選取全部。與分類全選共用同一套圖示、字型及無障礙選取提示。

<a id="section-40"></a>

## 40. 試用回饋：批次重複期間預設值

- 啟用「更改重複期間」時，期間欄的初值為 5 年，與生日匯入一致。批次期間項目仍預設未啟用；不主動套用，不改未選規則或既有事件。

<a id="section-41"></a>

## 41. 試用回饋：批次預覽就地展開／收合

- 「預覽變更」改為同頁可展開／收合的區塊，點標題或箭頭切換，不再另設預覽按鈕。選擇有效時展開才讀取；收合只隱藏內容，不清除確認過的預覽，也不寫入。
- 變更勾選規則或修改條件後舊預覽失效；若仍展開便更新，收合則等下次展開。期間修改仍須確認最新預覽，並在套用前重新核對。

<a id="section-42"></a>

## 42. 試用回饋：整批移除模式

- 「整批移除」改為和「更改分類／次類」相同形式的開關，預設關閉。開啟時自動關閉分類／次類及重複期間修改，清除其待套用預覽，保留已勾選的規則。關閉移除模式不自動恢復其他開關。
- 打開開關不刪除資料。勾選規則後按「套用」才顯示移除確認，列出將移除的規則和尚未開始的事件數，明確提供「取消」及「移除」按鈕，不靠點背景取消。確認後仍重新核對選取範圍，取消則返回原頁且不寫入。
- 三個開關依序為「更改分類／次類」、「更改重複期間」、「整批移除」，都放在規則勾選清單上方。

<a id="section-46"></a>

## 46. 試用回饋：規則列的下次日期使用整列寬度（待修改）

- 首頁正常為兩列：上列左側事件標題、右側規則摘要；下列左對齊「下次日期」或規則狀態。下列可用完整文字區寬度，最右到規則摘要右緣，不受上列標題欄限制。用完整日期和星期驗證，只有整列仍放不下時才換行（例如放大字級）。不改時間計算或兩側圖示位置。
- 下次事件若非全日，在完整日期與星期後加事件開始時間，沿用既有上午／下午格式及事件時區。全日事件不顯示時間。

<a id="section-49"></a>

## 49. 試用回饋：整批移除預覽（待修改）

- 開啟批次調整的「整批移除」後，沿用同頁可展開／收合的「預覽變更」。逐筆列出將移除的規則（含關聯子規則）與比對後可確認將刪除的尚未開始事件；事件顯示標題、日期及來源行事曆。已開始事件保留，不列為待刪；只有草稿而沒有事件時明確顯示零筆。
- 預覽不寫入。勾選變更時舊預覽失效，套用時用最新預覽重新核對待移除範圍，不只比筆數；發現變動先更新預覽再讓使用者確認。實際刪除仍須按「套用」後，在確認對話明確按「移除」。
