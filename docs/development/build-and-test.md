## 5. 建議里程碑與驗收

| 順序 | 驗收點 |
| --- | --- |
| 1. 日期與規則原型 | 不碰日曆就能預覽農曆、節氣與樹狀延伸日期；改根影響全樹，改子項不影響旁支。 |
| 2. UI 主流程 | 完成列表、規則主頁直接套用及唯讀預覽；驗證孫規則在祖父頁以縮排顯示、可收折但不可直接編輯；進入其父規則後可編輯，且不顯示旁支；驗證日期類型、週期、截止、持續期間與月底選項；驗證分類和次類可並排輸入或下拉選擇、分類必填、次類可空，以及最後一條規則移出後空分類消失。 |
| 3. 安全寫入 | 以獨立測試日曆驗證 iCloud／Google 的新增、重算、撤除、重複套用及權限拒絕；同名目的地不會誤寫，手動行程不會被動到。 |
| 4. 匯入與整體驗收 | 測選人、匯入預覽、取消、同名生日，以及匯入規則的分類歸屬。另確認「查看日曆」能否定位指定日期。 |

## 7. 日期邊界與待驗證事項

1. **期間換算的例外**：目前日週期直接加天數；月或年期間若算出的周年日不存在，會提示改用指定截止日期，不自行改日。仍可補充短月月底及閏日的驗證案例。
2. **農曆與節氣的例外**：西元支援年、月、週、日；農曆支援年、月，閏月和小月已實作並通過 11 項排程測試；節氣按年，依各規則的時區換算。子規則超出根規則起訖會阻擋套用，不會悄悄省略。
3. **技術驗證，不需先由使用者決定**：測試附註標記與同一期識別在 iCloud／Google 往返後的行為，驗證長區間大量事件的實機表現。首頁目前只開啟行事曆，未承諾定位指定日期。
