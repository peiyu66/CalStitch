User Guide

This guide uses English explanations alongside the relevant Chinese labels in the current test build.

Create a rule

  1. Tap “＋” on the home screen, choose Gregorian, lunar, or solar terms, then set the start date, repeat interval, and end condition.
  2. Enter an event title and category, choose a calendar, and set the all-day or start-time and duration options. The subcategory is optional.
  3. Open Preview Events (「預覽事件」) to check existing and planned events. Tap Apply (「套用」) to write them to your calendar.

The start date is the beginning of the scheduling window. For the second Sunday in May each year, you can start on May 1. Add child rules under a main rule to schedule reminders or follow-up events.

Choose a calendar

When you first tap Connect Calendar (「連接行事曆」), grant full access so CalStitch can read back events it creates. Read-only calendars are listed but cannot be selected. If your iPhone already syncs your iCloud or Google calendar, there is no extra sign-in. For your first test, try a dedicated calendar.

Import birthdays

Open Import Birthdays (「匯入生日」) from the home screen. Pick individuals in the system contact picker, or grant full Contacts access to import by group. If access was denied or limited, change it in iPhone Settings and return to CalStitch.

Review the birthdays and choose a destination calendar before importing. Draft (「草稿」) saves the rules only. Import and Apply (「匯入後套用」) also writes the events when the import completes.

Edit in bulk and remove events

Use Batch Edit (「批次調整」) to update categories, subcategories, or repeat periods. Batch Remove (「整批移除」) deletes the selected rules and matching events that have not started, only after you tap Apply and confirm. Events that have already started are kept.

Clean Up Leftover Events (「清除遺留事件」) finds tagged CalStitch events without a matching rule on this iPhone. If you use the same calendar on multiple devices, check that another device does not manage the events before deleting them.

Solar terms and current limitations

Solar term dates are available offline for 1901–2100. The default time zone applies to new solar term rules and does not shift existing events. The test build may block certain lunar rules involving leap months or short months.
