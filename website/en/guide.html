User Guide

Create a rule

  1. Tap “＋” on the home screen, choose Gregorian, lunar, or solar terms, then set the start date, repeat interval, and end condition.
  2. Enter an event title and category, choose a calendar, and set the all-day or start-time and duration options. The subcategory is optional.
  3. Open Preview Events to check existing and planned events. Tap Apply to write them to your calendar.

The start date is the beginning of the scheduling window. For the second Sunday in May each year, you can start on May 1. Add child rules under a main rule to schedule reminders or follow-up events.

Choose a calendar

When you first tap Connect Calendar, grant full access so CalStitch can read back events it creates. Read-only calendars are listed but cannot be selected. If your iPhone already syncs your iCloud or Google calendar, there is no extra sign-in. To try scheduling without affecting your main calendar, choose a separate calendar.

Import birthdays

Open Import Birthdays from the home screen. Pick individuals in the system contact picker, or grant full Contacts access to import by group. If access was denied or limited, change it in iPhone Settings and return to CalStitch.

Choose whether to use names or nicknames for event titles. If a contact has no nickname, CalStitch uses their name. Review the birthdays and choose a destination calendar before importing. Draft saves the rules only. Import and Apply also writes the events when the import completes.

Edit in bulk and remove events

Use Batch Edit to update categories, subcategories, or repeat periods in years, months, or days. In Remove Selected Rules, preview the rules, their child rules, and upcoming events to be removed. Tap Apply and confirm to remove them. Events that have already started are kept.

Clean Up Leftover Events finds tagged CalStitch events without a matching rule on this iPhone. If you use the same calendar on multiple devices, check that another device does not manage the events before deleting them.

Lunar leap months and short months

Yearly rules for a regular lunar month use only the regular month. If you choose a leap month, the event uses that leap month when it occurs and the regular month of the same name in other years. Monthly rules include leap months by default; you can turn this off. If you choose day 30, an occurrence in a 29-day month falls on day 29 without changing the rule.

Solar terms and time zones

Solar term dates are available offline for 1901–2100. The default time zone applies only to new solar term rules. Changing it does not move existing events.
