User Guide

Create a rule

  1. Tap “＋” on the home screen, choose Gregorian, lunar, or solar terms, then set the start date, repeat interval, and end condition.
  2. Enter an event title and category, choose a calendar, and set the all-day or start-time and duration options. The subcategory is optional.
  3. Check existing and planned events in Preview Events. It opens automatically when you create a rule or begin making changes to an existing rule, without scrolling away from the current field. Tap Apply to write them to your calendar.

The start date is when scheduling begins. It does not have to be the date of the first event. Add child rules under a main rule to schedule reminders or follow-up events.

Example: Mother’s Day on the second Sunday in May

  1. Tap “＋” to create a rule. Under Date and Recurrence, set Type to Gregorian and set Start Date to May 1 of the first year you want to schedule, for example, May 1, 2027.
  2. Set Repeat Cycle to Year and leave the interval at 1 year.
  3. Under Date Pattern, switch from Fixed Month and Day to Fixed Weekday, then select “2nd” and “Sunday.”

The month comes from the start date. There is no separate month picker. In this example, Next Date shows May 9, 2027. Choose a calendar, check Preview Events, then tap Apply.

Choose a calendar

When you first use CalStitch, grant full Calendar access from the home screen so it can verify events it creates. Read-only calendars are listed but cannot be selected. If your device already syncs your iCloud or Google calendar, there is no extra sign-in. To try scheduling without affecting your main calendar, choose a separate calendar.

Import birthdays

Open Import Birthdays from the home screen. Pick individuals in the system contact picker, or grant full Contacts access to import by group. If access was denied or limited, change it in Settings on your device and return to CalStitch.

Birthday titles use nicknames by default, or names if no nickname is available. You can switch to names. Birthdays ready to import are selected by default. Select All acts on the current Gregorian or lunar filter. Choose a calendar, then tap Import at the top right to write the rules and events. Cancel at the top left makes no changes.

When the birthday matching code matches, CalStitch marks the entry as “Already imported” and prevents you from selecting it. If the code cannot confirm a match but an existing rule matches the contact’s name or nickname and birthday, CalStitch marks it as “Possible duplicate.” Select All skips these entries, but you can review and select them individually.

Edit in bulk and remove events

Use Batch Edit to update categories, subcategories, or repeat periods in years, months, or days. In Remove Selected Rules, preview the rules, their child rules, and upcoming events to be removed. Tap Apply and confirm to remove them. Events that have already started are kept.

Clean Up Leftover Events lists tagged CalStitch events with no matching rule. It excludes events in pending operations or removed in the last two hours. Select only events you no longer need. CalStitch checks the selection again before deleting, and asks you to choose again if the list has changed.

Sync across iPhone and iPad

When both devices use the same Apple Account, CalStitch syncs rules and category order through your private iCloud database. Groups stay expanded or collapsed independently on each device. Your calendar provider syncs events. Receiving a rule on another device does not recreate its events.

To change a main rule’s calendar, choose a new destination and check Preview Events before applying. Upcoming events and child rules are included, while events that have started or passed stay in the original calendar. CalStitch does not create a second set of events if the original calendar is unavailable or read-only.

Lunar leap months and short months

Yearly rules for a regular lunar month use only the regular month. If you choose a leap month, the event uses that leap month when it occurs and the regular month of the same name in other years. Monthly rules include leap months by default; you can turn this off. If you choose day 30, an occurrence in a 29-day month falls on day 29 without changing the rule.

Solar terms and time zones

Solar term dates are available offline for 1901–2100. The default time zone applies only to new solar term rules. Changing it does not move existing events.
