# CalStitch

[中文](README.md)

CalStitch is a calendar rule tool for iPhone and iPad. Set up rules in CalStitch and see the resulting events in the calendar you already use.

- Schedule recurring events by Gregorian dates, lunar dates, or the 24 solar terms.
- Import birthdays you select from Contacts by name or nickname into a calendar of your choice.
- Organize rules by category and subcategory, and use child rules for preparation or follow-up.
- Preview events before applying changes, and edit multiple rules at once.
- Browse categories and rules side by side on iPad. Sync rules and category order through iCloud on devices signed in to the same Apple Account.

Add only the holidays, anniversaries, and contacts’ birthdays you want to your own calendar. There’s no need to subscribe to a full holiday calendar or show every contact’s birthday.

Available in Chinese and English. [Get CalStitch for iPhone and iPad on the App Store](https://apps.apple.com/app/calstitch/id6838189548).
