# CalStitch

[中文](README.md) · English

CalStitch is an iPhone tool for calendar rules. Set up rules in CalStitch and see the resulting events in the calendar you already use.

- Schedule recurring events by Gregorian dates, lunar dates, or the 24 solar terms.
- Import birthdays from Contacts as drafts or apply them to a selected calendar.
- Organize rules by category and subcategory, and use child rules for preparation or follow-up.
- Preview events before applying changes, and edit multiple rules at once.

Add only the holidays, anniversaries, and contacts’ birthdays you want to your own calendar. There’s no need to subscribe to a full holiday calendar or show every contact’s birthday.

CalStitch is currently in testing and is not available on the App Store. English documentation is available; the current test build uses a Chinese interface.
